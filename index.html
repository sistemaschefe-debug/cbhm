REGRAS DE SEGURANÇA — CONFIGURAÇÃO CORRETA

O app agora usa Firebase Authentication. Suas regras atuais estão corretas — só precisam permitir leitura pública para o placar e dados de sessão ao vivo (equipes participantes acessam sem login). Use as regras abaixo: 

{
  "rules": {
    "admins": {
      ".read":  "auth != null && root.child('admins').child(auth.uid).val() === true",
      ".write": false
    },
    "config": {
      ".read":  true,
      ".write": "auth != null && root.child('admins').child(auth.uid).val() === true"
    },
    "questions": {
      ".read":  "auth != null && root.child('admins').child(auth.uid).val() === true",
      ".write": "auth != null && root.child('admins').child(auth.uid).val() === true"
    },
    "teams": {
      ".read":  true,
      ".write": "auth != null && root.child('admins').child(auth.uid).val() === true"
    },
    "activeSession": {
      ".read":  true,
      ".write": "auth != null && root.child('admins').child(auth.uid).val() === true"
    }
  }
}
Para cadastrar o UID do administrador no banco:
1. Vá em Authentication → Users → copie o UID do seu usuário
2. Vá em Realtime Database → Data → (+) Adicionar nó
3. Crie: admins → {SEU_UID} → true

SOBRE O EVENTO

O CBHM é um marco na valorização da História Militar na formação dos futuros líderes. O evento reúne equipes de 8 estabelecimentos de ensino militares em uma competição de conhecimento histórico com pontuação por velocidade de resposta.

TABELA DE PONTUAÇÃO
0–5s Resposta até 5 segundos 30 pts
6–10s Resposta de 6 a 10 segundos 25 pts
11–15s Resposta de 11 a 15 segundos 20 pts
16–20s Resposta de 16 a 20 segundos 15 pts
21–30s Resposta de 21 a 30 segundos 10 pts
